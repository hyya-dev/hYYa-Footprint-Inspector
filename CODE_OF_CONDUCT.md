# Code of conduct

This project is about respecting people's privacy, and we expect the same respect between
contributors.

- Be kind and assume good intent.
- Critique ideas, not people.
- No harassment, discrimination, personal attacks or sharing others' private information.
- Keep discussions on topic.

Maintainers may edit or remove comments, issues or pull requests that break these rules, and may
block repeat offenders. To report a problem privately, email **security@hyya.com**.
