# Security policy

hYYa Digital Footprint Check has no server and collects no data, so the realistic risks are in the app
itself:
- a value read or shown in a way that leaks it
- something stored that shouldn't be
- a claim in the app that isn't true

## Reporting a vulnerability

Please report privately. Don't open a public issue. Either:

- use GitHub's **Report a vulnerability** button on the Security tab, or
- email **security@hyya.com**.

Please include:
- what you found
- how to reproduce it
- the device and system version (iOS, iPadOS, macOS or Android)
- the app version, from Settings in the app

We'll acknowledge it within a few days, keep you updated, and credit you in the release notes if
you'd like.

## Supported versions

Only the latest release on each store receives fixes: the App Store (iPhone, iPad and Mac) and
Google Play (Android), plus `main`. Signed Android APKs on GitHub Releases follow the Google Play
version.
