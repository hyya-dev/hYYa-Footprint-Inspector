hYYa Footprint Inspector is a free privacy-education app. It reads the same device information any iOS app can read and shows it ONLY to the person holding the device, so they can see their own "fingerprint" and reduce it. Nothing is collected, stored off the device or transmitted: there is no account, no server, no analytics and no third-party SDK. The App Privacy label is "Data Not Collected".

No login is required. To review:
1. Tap "Start with check 1" on the first screen. Results appear in about 3 seconds, with one privacy score that averages the checks done so far.
2. Tap any clue to see what it reveals and how to fix it. "Fix them with me" walks through fixable clues and opens Settings; the app changes no setting itself.
3. Each permission category ("Seen once you allow it") asks for that permission only when the user taps "Show me", then shows counts and summaries (never contacts' names, numbers or event titles).
4. "Sensitive apps" tab: the user picks categories, then taps Check.
5. "Tracker" tab: the user opens the App Privacy Report file they saved from Settings with the system file picker. It is read on the device only; never stored or sent.

About CallKit (guideline 5, China): the app no longer includes or links CallKit in any territory.

About VPN (automated question, 2026-10-19): the app has NO VPN functionality. It has no Network Extension entitlement, creates no VPN configuration or tunnel, routes no traffic and makes no network connections of its own. Two read-only checks mention VPNs: (1) one finding shows the user whether a VPN is currently on, read from the system proxy settings (CFNetworkCopySystemProxySettings), because any app can see this; (2) the user-initiated "Sensitive apps" check can test whether four VPN and censorship-circumvention apps are installed (URL schemes psiphon, onionhttp, protonvpn, nordvpn, declared in LSApplicationQueriesSchemes). Both are only shown to the device owner and never sent; only a count of the sensitive apps found stays on the device, never which ones.

About fingerprinting (5.1.2): the app does not fingerprint anyone. Every value is displayed to the device owner on screen and never leaves the device. Scan history keeps only salted one-way hashes, the score and the ids of notable findings, never the values, and is excluded from backups.

About LSApplicationQueriesSchemes (25 schemes): these are used only for the user-initiated "Sensitive apps" check, which shows the user which kinds of apps any other app could detect on their device with canOpenURL. Categories are off by default, results are blurred until tapped, cleared when the app leaves the screen, and never sent. Only the count found stays on the device, never which apps.

About Required Reason APIs: system boot time, disk space, active keyboards, file timestamps and user defaults are read solely to display them to the user as part of the privacy report. The privacy manifest declares them.

The app's keychain items hold only its own install dates, as an on-device demonstration that apps can recognise a reinstall, and the widget's copy of the score and last-check date. Both are ThisDeviceOnly and never synced.

Motion sensors are also used for a subtle tilt effect on the mascot. Nothing is recorded.

The app uses only Apple frameworks. StoreKit and MusicKit are used to show the App Store country, the original download date and Apple Music subscription status to the user.

Check-up's guidance steps (updates, weekly restart, leaked passwords, Lockdown Mode) are instructions only: the app detects no malware and reads no passwords.
Optional local re-scan reminder: asked for only when chosen. No server, no push.
New in 1.0.3: a Home Screen widget showing only the privacy score and the date and time of the last check. It makes no network connections and shows no finding or app name.
